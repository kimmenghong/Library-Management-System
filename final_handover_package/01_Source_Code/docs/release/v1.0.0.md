# Release Notes

## Summary

Version 1.0.0 is the first stable final release of the corrected Library Management System. This release focuses on the lecturer's required 11-table Data Dictionary and provides a complete Django web application for the main library workflows.

## Completed Features

- Custom authentication using the `users` table.
- Role management using the `roles` table.
- User management.
- Category management.
- Author management.
- Publisher management.
- Book catalog and stock management.
- Member management.
- Book borrowing workflow.
- Book returning workflow.
- Automatic book availability updates.
- Late return fine calculation.
- Fine payment tracking.
- Member notifications.
- Report generation history.
- CSV report generation.
- Dashboard statistics.
- Django Admin configuration.
- Sample data command.
- Automated test suite.
- Final documentation package.

## Database Compliance

The active application schema contains exactly 11 Library Management System tables:

1. `roles`
2. `users`
3. `categories`
4. `authors`
5. `publishers`
6. `books`
7. `members`
8. `borrow_records`
9. `fines`
10. `notifications`
11. `reports`

Verified corrections:

- `BorrowRecord` uses `book_id` FK to `books`.
- `BorrowRecord` includes `issued_by` and `received_by` FKs to `users`.
- `Notification` uses `member_id` FK to `members`.
- `Report` uses `generated_by` FK to `users`.
- All primary keys match the lecturer requirement.
- All active table names match exactly with `db_table`.

## Known Limitations

- Reservations are not active because the corrected lecturer schema does not include a `reservations` table.
- Active REST API routes are not included in v1.0.0.
- PDF and Excel export are future enhancements.
- Email reminders are future enhancements.
- Barcode and QR code printing are future enhancements.
- SQLite is used for development; PostgreSQL or MySQL is recommended for production.
- Older inactive phase folders may exist in the workspace and should be excluded or archived for strict final submission.

## Upgrade Notes

This is the first stable release. For a clean installation:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 manage.py migrate
python3 manage.py seed_data
python3 manage.py runserver
```
