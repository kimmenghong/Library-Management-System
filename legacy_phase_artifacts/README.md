# Legacy Phase Artifacts

These folders contain earlier phase-by-phase modules and templates from the
project-building process. They are preserved for documentation/reference only.

The production application uses the final lecturer-aligned 11-table schema in:

- `apps/library`
- `templates/library`
- `templates/registration`
- `static`

Do not add these legacy apps back to `INSTALLED_APPS` unless the lecturer's
11-table Data Dictionary requirement changes.
